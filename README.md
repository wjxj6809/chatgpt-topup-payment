### 第二步：自己取 token

整个流程里最容易出错的就是这一步。

先用浏览器正常登录 chatgpt.com，确认账号状态没问题，然后在地址栏打开会话信息页面（chat.openai.com/api/auth/session）。页面会显示一段 JSON 格式的文本，里面是你的账号认证 token。

接下来 Ctrl+A 全选、Ctrl+C 复制，一个字符都不能少。很多充值失败不是卡密的问题，而是 token 少复制了头尾的字符。

两个细节值得注意。token 相当于你账号的临时登录凭证，平台靠它以你的登录状态完成订阅操作，所以它和密码一样敏感，不要发到群里，也不要截图给人。操作时建议用隐私模式，避开浏览器插件的干扰；充值前后尽量用同一个浏览器、同一台设备，减少额外的风控验证。

### 第三步：提交充值，验证到账

回到充值页面，把卡密和 token 粘贴进去，提交。处理通常在一到五分钟内完成，最迟不超过三十分钟。

判断到账很简单：刷新 ChatGPT 页面，左下角账号信息出现 Plus 标识；邮箱一般也会收到标题带 "ChatGPT Plus" 或 "subscription" 的确认邮件，记得翻一下垃圾邮件文件夹。

提交之后迟迟没显示的，先别急着重新下单。Ctrl+F5 强制刷新页面、确认登录的是同一个账号、清一下浏览器缓存——不少“没到账”其实就是缓存在作怪。确认订单状态无误再联系售后，不要连续提交多个 token，越提交越乱。
